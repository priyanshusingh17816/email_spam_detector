# Email Spam Detector

A simple machine-learning web application that classifies email messages as **SPAM** or **NOT SPAM**.

## Technologies
- Python
- Flask
- Scikit-learn
- TF-IDF
- Logistic Regression
- HTML/CSS

## How to run

```bash
pip install -r requirements.txt
python train_model.py
python app.py
```

Then open:

`http://127.0.0.1:5000`

## Note
The included dataset is a small demo dataset for learning purposes. For a real spam filter, use a larger labeled email dataset.
